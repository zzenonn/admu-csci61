# Slides

Lecture slides as [Bento](https://bento.page) decks on the
[DISCS Bento template](https://github.com/zzenonn/discs-bento-template).
Each deck is one self-contained HTML file. Open it in a browser to present.
Press **Esc** to edit, **S** for the speaker view, and **Ctrl/⌘ S** to save.

Decks 01–06, 08 and 09 were converted from the PDF slides. Icons and diagrams are kept from
the originals, and all text is editable.

07 Cryptography Hands-On was written for this format. Its code runs as shown,
and the same code is in [`notebooks/07_cryptography_hands_on.ipynb`](../notebooks/07_cryptography_hands_on.ipynb).

10 Digital Forensics was also written for this format. Its terminal output comes from The Sleuth Kit,
run on a small demo disk that is separate from the Lab 08 image. The hands-on part is
[Lab 08](../labs/lab08_sleuthkit_and_autopsy.md).

`screenshots/` has a picture of every slide, one folder per deck.
